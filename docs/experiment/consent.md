# 학습 도구 사용 실험 참여 안내와 동의서

- 이 문서는 참여자에게 실험 전에 보여 주고, 진행자가 읽어 준 뒤 동의를 받는 데 쓴다.
- 인쇄하거나 화면으로 보여 준다. 서명 대신 참여자 코드와 동의 표시만 받는다.

## 1. 무엇을 하나요

- 두 가지 학습 도구로 자료구조·운영체제·데이터베이스·네트워크·컴퓨터구조 중 배운 과목의 개념을 공부해 보고, 어떤 점이 도움이 되는지 살펴보는 실험입니다.
- 진행 순서(안내·단계 전환을 포함해 약 75~90분, 후보 개념 8~13개 기준)
  1. 사이트를 열기 전에 종이로 선수 개념 확인 문제 풀기(약 15분)
  2. 배우지 않은 과목의 개념을 제외한 뒤 사전 문제 풀기(후보 8개면 12분, 10개면 15분, 13개면 20분)
  3. 개념 하나를 읽으며 첫 번째 도구로 공부하기(최대 15분)
  4. 다른 개념 하나를 읽으며 두 번째 도구로 공부하기(최대 15분)
  5. 짧은 사후 문제 풀기(약 10분)
  6. 설문(약 5분)
- 사전 문제는 남은 후보 개념마다 2문항이며, 개념당 1.5분을 올림한 시간을 줍니다. 후보가 적거나 일찍 끝내면 전체 시간도 줄어들 수 있습니다.
- 종이 문제는 과목별로 묶여 있습니다. 수강하지 않은 과목은 "미수강"이라고 쓰고 건너뛰세요. 배웠지만 모르는 문제는 비워 두거나 "모름"이라고 써도 됩니다. 이 답으로 학습할 개념을 정하지 않으며, 실험이 끝나기 전에는 정답이나 점수를 알려 드리지 않습니다.
- 성적이나 평가와는 관계가 없습니다. 문제를 틀려도 괜찮습니다.

## 2. 어떤 정보를 모으나요

| 모으는 것 | 쓰임 |
| --- | --- |
| 참여자 코드(예: S1), 학년, 자료구조 수강 여부, 제외한 개념 | 참여자 구성을 설명할 때 |
| 종이·화면 문제에 쓴 답, 도구와 나눈 대화, 각 단계에 걸린 시간 | 선수 지식과 진단을 대조하고 두 도구의 학습 효과를 비교할 때 |
| 설문 응답 | 도구에 대한 의견을 정리할 때 |

- 이름, 연락처, 학번, 성적은 모으지 않습니다.
- 종이 답안은 진행자가 보관하고, 입력한 답과 대화 등 디지털 기록은 이 프로젝트를 진행하는 컴퓨터 안에만 저장합니다. 외부 서비스로 보내지 않습니다.
- 분석이 끝나면 종이 답안을 파기하고 입력한 답과 대화 원문은 지우고, 참여자를 알아볼 수 없는 수치만 남깁니다.
- 결과는 졸업 프로젝트 발표에 참여자 코드나 묶음 수치로만 쓰입니다.

## 3. 참여는 자유입니다

- 언제든 이유를 말하지 않고 그만둘 수 있습니다. 그만두어도 불이익은 없습니다.
- 그만두면서 원하면, 그때까지 모은 정보를 바로 지웁니다.

## 5. 설문 (실험 끝에 화면에서 답함)

1. 첫 번째 도구는 막힌 부분을 이해하는 데 얼마나 도움이 됐나요? (1 전혀 아니다 ~ 5 매우 그렇다)
2. 두 번째 도구는 막힌 부분을 이해하는 데 얼마나 도움이 됐나요? (1 ~ 5)
3. 다음에 비슷한 상황에서 막히면 어느 도구를 쓰고 싶나요? (첫 번째 / 두 번째 / 상관없음)
4. 글을 읽다가 어디서, 왜 막혔나요? (자유 서술)
5. 그 밖에 하고 싶은 말이 있나요? (자유 서술)
